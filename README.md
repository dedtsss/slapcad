# КолхозCAD

Независимая инженерная среда для AI-агентов: параметрическое 3D-моделирование, модификация деталей, измерения, чертежи, изучение практического опыта и расчёты.

**Главный пользовательский сценарий:** владелец общается с агентом на русском языке (ChatGPT Workspace Agent, Hermes либо иной клиент), говорит «добавь три отверстия», «покажи расстояние», «предложи крепление», получает проверенные изображения/размеры и обновляемую 3D-модель по защищённой ссылке телефона. Сам CAD-редактор пользователь не открывает.

**Принцип:** движок, исходники моделей, правила, навыки, результаты и просмотрщик принадлежат этому репозиторию/изолированной среде; ChatGPT, Hermes, MCP и способы подключения — сменные оболочки. Никакого переноса инженерной логики в конкретного клиента.

## Границы

Открытый исходный код предпочтителен, без подписных CAD-сервисов и зависимости от одной модели. Сначала простейший доказанный рабочий путь (CLI/JSON + существующие геометрические средства), затем по необходимости лёгкий серверный адаптер, расчётный модуль и защищённый 3D-просмотр.

**Создание задачи не запускает реализацию.** Любая установка на VPS, изменение инфраструктуры или старт Codex допускаются только после отдельной команды владельца.
