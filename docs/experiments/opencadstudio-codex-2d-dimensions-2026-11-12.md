# Codex на HangarVPS: отдельный 2D-чертёж с размерными объектами (12.11.2026)

**Статус: PASS для 2D DWG и независимого аудита.** Codex CLI 0.167.0 с gpt-6.1-sol, авторизованный через ChatGPT, сам создал два неассоциативных вида через локальный MCP OpenCADStudio v2026.45, нанёс действительные CAD-размеры, сохранил DWG2018, повторно открыл его и штатно завершил сеанс (exit=0, turn.completed, собственный final.txt).

## Геометрия и результат

- Исходная 3D-модель осталась неизменной: размеры испытательной детали 200×140×40 мм, верхняя площадка 90×50×28, две боковые стенки 10×80×18, пять отверстий (центральное Ø26, четыре Ø10).
- Вид сверху: контур плиты 200×140, прямоугольники площадки и двух боковых рёбер, пять окружностей. Вид спереди размещён под первым на чертёжной плоскости, отображает основание 12 мм, выступ 28 мм и рёбра 18 мм.
- Действительные команды PLINE, CIRCLE, DIMLINEAR и TEXT прошли через локальный MCP; введены русские подписи и семь размерных объектов со значениями 200, 140, 90, 50, 40, 12, 28 мм.
- После независимого открытия DWG отдельным OpenCADStudio --serve: 8 Polyline, 5 Circle, 7 Dimension и 12 Text. Из них 5 Text введены моделью, дополнительные 7 создаются представлением семи размеров после сохранения/открытия. Дополнительно в манифесте 25 Line и 14 Solid из отображения размеров; они не означают лишних 3D-тел.
- Независимо сверены все восемь четырёхугольных контуров, центры и радиусы всех пяти окружностей, наличие пяти исходных подписей и семи числовых надписей размеров. Аудит DWG: 0 ошибок, 0 предупреждений.
- Событийный журнал: 41 завершённый вызов нативного MCP; итог Codex exit=0. Расход по статистике модели: 460 500 входных токенов (394 496 из кэша), 2 185 выходных; это не бухгалтерский расчёт стоимости.

## PDF и снимок

- Codex сам PDF не выпустил: две попытки вызова op=plot с параметрами во вложенном parameters были отклонены. Модель корректно завершилась с сохранённым DWG и указала ограничение.
- Отдельный процесс OpenCADStudio --serve успешно выполнил op=plot с ключами path/layout/fit/center на верхнем уровне запроса и создал 2D PDF 35 742 байта (валидный заголовок PDF и метка конца файла). Снимок 2D вида создан через настоящее GUI/MCP, разрешение 729×579, 35 056 байт.
- Визуальная проверка снимка выявила слишком мелкие размерные надписи и тесное расположение одной подписи. Не выдавать штатный PDF-предпросмотр за оформленный рабочий чертёж.
- В этом же сеансе ChatGPT отдельно создан аккуратный контрольный лист A3 в векторном PDF на основе подтверждённых числовых размеров. Это дополнительный визуальный материал, **не** автоматически спроецированный из 3D B-rep; бинарный PDF приложен к ответу в чате, в репозиторий не загружен. В нём явно указано, что он не для изготовления.
