# OpenCADStudio на HangarVPS — проверка 09.11.2026

**Статус:** локальные 2D/3D, файлы и управление через MCP проверены; вызов GPT-6 Astra через API **не выполнялся** (защита инструментального канала прервала попытку обращения с временным ключом). Это самостоятельный эксперимент, **не замена** AgentCAD/build123d на BrainVPS и **не точная модель TODOMA**.

- Отдельная учётная запись без административных прав: `ocstest`; каталог: `/home/ocstest/opencadstudio/`.
- Двоичный выпуск `OpenCADStudio-v2026.45-linux-x86_64.AppImage` из официального GitHub, SHA-256 `85ee7838059eebc1c913bd2fbab42c579983f4281464cbb3b190fc06f4077ec2` — совпал с опубликованным хешем.
- Для GUI под `Xvfb` понадобился `libxkbcommon-x11-0`. Графика программная (llvmpipe), без аппаратного GPU; рабочие службы сервера не перезапускались.
- Codex CLI на Ангаре отсутствовал и ради эксперимента не устанавливался. Постоянных сервисов/открытых портов OpenCADStudio не создавалось.

## Реальные испытания

1. **2D, `--serve`:** полилиния-контур 200×200 и четыре окружности радиуса 7 в центрах (25,25), (175,25), (175,175), (25,175). Ответ `entities`: 1 `Polyline`, 4 `Circle`; запрос `query` подтвердил точные координаты и радиусы. Это двумерная заготовка, **не подтверждённая пластина с прорезанными сквозными отверстиями в 3D**.
2. **DWG/DXF/PDF:** проверка `audit` перед DWG2018: 0 ошибок, 0 предупреждений, `dropped_on_save=0`; `save_verified` успешен, DWG = 27 347 байт. Штатный `--export` успешно преобразовал DWG→DXF. Вывод чертежа в PDF: 1 лист 297×210 мм, 2 783 байта.
3. **3D, `--serve`:** `BOX 0,0,0 200,200,0 10` создал `3D Solid`. Запрос `measure` вернул границы 200×200×10, объём ~400 000 куб. ед. и площадь поверхности 88 000 кв. ед. Это контрольная призма без отверстий.
4. **MCP, `--mcp` в `xvfb-run`:** возвращаются 20 инструментов. После установки недостающей системной библиотеки реальный редактор запустился; испытание выполнено с 11 вызовами инструментов. Проверенное сохранение `DWG 2000`, `DWG 2013`, `DWG 2018`, `DXF 2000`; получен реальный PNG снимок окна чертежа 729×579.
5. **Расхождение испытательного сценария с новой версией:** официальный `mcp_smoke.py` предполагал ровно четыре инструмента, хотя установленная версия возвращает двадцать; `mcp_acceptance.py` предполагал изображение первым элементом ответа, хотя теперь перед ним текстовые пространственные данные. Для проверки создана локальная копия `mcp_acceptance_compat.py` с выбором элемента по `type=image`; повторная полная проверка завершилась `ok=true`. Это поправка к сценарию, не исправление движка.

## 09.11 — дополнение: работающий GPT-6.1 Sol → OpenCADStudio, без копирования секретов

**Статус самостоятельного ограниченного сценария: PASS.** Исходный тест Astra выше остаётся исторически верным; новый успешный тест — **другая модель `gpt-6.1-sol`** и другая схема.

### Проверенная схема

`Bruce Secrets → BruceVPS (OpenAI API / gpt-6.1-sol → проверенный числовой JSON-план) → SSH/Tailscale (ТОЛЬКО план) → HangarVPS:ocstest (OpenCADStudio --serve → DWG/DXF/PDF + audit)`.

- `OPENAI_OPENCADSTUDIO_API_KEY` существует в Bruce Secrets. Штатный секретозависимый вызов `BruceVPS.secret_http_get` к `/v1/models/gpt-6.1-sol` вернул допустимую модель. Вызов `/v1/responses` с ключом, внедрённым в `OPENAI_API_KEY` только внутри процесса BruceVPS, выполнился: **HTTP 200 / completed**.
- `HANGARVPS_API_KEY` — уже созданный токен Bitwarden из машинной записи `Brain` с названием `Hangar`; его копия хранится в Bruce Secrets. На Bruce вызов `bws project list` от имени этого токена завершился успешно и вернул `DevelopersCat`. Новый токен не выпускался.
- Перенос токена Bitwarden из Bruce на Hangar был остановлен системой безопасности инструмента, описано в `dedtsss/agent-dispatch/docs/memory/bitwarden-hangar-admin-route-2026-11-09.md`. **Эту блокировку не обходили.** Вместо этого создана архитектура, вообще не требующая передачи ни токена Bitwarden, ни ключа OpenAI на Hangar: API-вызовы и доступ к центральным секретам выполняются на Bruce, удалённое выполнение CAD принимает исключительно числовые параметры.
- Контроллер Bruce `/opt/opencadstudio-pilot/sol_to_cad.py`; код: [tools/opencadstudio/sol_to_cad.py](../../tools/opencadstudio/sol_to_cad.py). Его SSH-дочерний процесс стартует с очищенным окружением, без `OPENAI_API_KEY`, соединяется с известным проверенным ключом хоста по Tailscale и не выполняет команды, сформированные языковой моделью.
- Рабочий обработчик Hangar `/home/ocstest/opencadstudio/cad_build.py`; код: [tools/opencadstudio/cad_build.py](../../tools/opencadstudio/cad_build.py). Он принимает **только** `rectangular_plate` с ограниченными размерами, валидирует числа и создаёт пять допустимых 2D сущностей через реальный `OpenCADStudio v2026.45 --serve`, проверяет аудит, сохранение DWG 2018 и экспорт DXF и PDF.
- Для выдачи готовых файлов владелец имеет частный Termalin-сайт `ec0dabb4-876a-4cf5-a7b8-5a8e2e0a63aa`, открытие через [личный кабинет Termalin](https://termal.in/account#open-site=ec0dabb4-876a-4cf5-a7b8-5a8e2e0a63aa&page=%2F). На Hangar включена только сервисная публикация **уже готовых файлов** `opencadstudio-pilot-files.service` (Unix UID `ocstest`, Python http.server, исключительно `127.0.0.1:18891`; ограничены права службы, ресурсы и файловый доступ). Публичный сетевой порт не открыт, доступ к ссылке требует авторизованного владельца Termalin. Сам CAD движок не запущен фоновым сервисом.

### Границы / дальнейшее развитие

- Это **работающий, но узкий прототип**. Языковая модель **выбирает только числа и тип шаблона**, а проверенный обработчик выполняет ограниченные CAD-команды. Это **не** свободное самостоятельное управление всеми 20 инструментами MCP, не универсальная чертёжная система и не проверенная инженерная модель для изготовления.
- Круги представляют двумерные контуры отверстий, **не** подтверждают сквозные отверстия объёмного тела. Отдельное 3D тело без вычитания ранее протестировано, не путать.
- Прямой `bws` от имени `ocstest` на Hangar **не авторизован**. Для данного пути он не требуется. Если нужен независимый доступ других программ с Hangar к Bitwarden, это отдельная работа с утверждённым механизмом выдачи/хранения идентичности, не обходить заблокированный перенос.
- Откат: удалить `/opt/opencadstudio-pilot` на Bruce, обработчик `cad_build.py` на Hangar и `opencadstudio-pilot-files.service` после `systemctl disable --now`; снять частный Termalin-сайт. **Не трогать** существующие ключи Bruce Secrets и ранее установленный CAD движок. Рабочие службы Cat/Bruce/Brain не перезапускались.
