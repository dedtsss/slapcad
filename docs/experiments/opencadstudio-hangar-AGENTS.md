# КолхозCAD · работа на HangarVPS

Ты работаешь **локально на HangarVPS** под непривилегированным пользователем `ocstest`. Предпочитай прямой инструмент MCP `opencadstudio` в Codex, зарегистрированный в ~/.codex/config.toml. Не вызывай модель через BruceVPS и не передавай секреты между серверами.

## Контекст
- OpenCADStudio v2026.45: `./OpenCADStudio-v2026.45-linux-x86_64.AppImage`, доступен в MCP под Xvfb.
- Чертежи, отчёты и виды: `./results/sol-pilot/`.
- Подтверждённые команды: `BOX`, `CYLINDER`, `UNION`, `SUBTRACT`; для булевых операций сначала очищай выделение, затем выбирай основание и режущие тела отдельно.
- Сначала изучай реальную структуру документа и доступные команды; по возможности работай непосредственно инструментами MCP.
- Действительное окончание задачи требует проверить количество тел, измерить геометрию, выполнить аудит, сохранить и заново открыть чертёж, сравнить размеры/объёмы.
- Отчёты о 2D/3D испытаниях: `https://github.com/dedtsss/kolkhozcad/tree/main/docs/experiments`.

## Границы
- Не читай, не копируй и не пересылай закрытые ключи и файлы `~/.codex/auth.json`, `~/.config/bws/`, файлы *.env, системные настройки и ключи хранилищ.
- Не выполняй системные изменения, не устанавливай пакеты, не меняй пользователей/SSH/сетевые службы без явного отдельного разрешения.
- Не удаляй и не изменяй результаты прежних испытаний. Новые файлы создавай с уникальными именами.
- Не объявляй объект пригодным для изготовления без необходимых видов, размеров, допусков, материалов и независимой проверки.
- Описывай, какие операции и файлы действительно созданы; неизвестное отмечай.



## Проверенная короткая последовательность
- Начни с `ocs_sessions` и `ocs_new`; затем `ocs_run` для числовых команд `BOX x1,y1,z1 x2,y2 HEIGHT` и `CYLINDER x,y,z RADIUS HEIGHT`.
- Для `UNION` надёжнее единый `ocs_execute` batch: `select(clear=true)`, `start UNION`, `input(selection, handles=[...])`, `input(enter)`. Вычисляй актуальные идентификаторы через `ocs_query`, никогда не угадывай их.
- Для `SUBTRACT` надёжнее единый batch: `select(clear=true)`, `start SUBTRACT`, `input(selection, handles=[base])`, `input(enter)`, `input(selection, handles=[cutters...])`, `input(enter)`.
- Сразу после построения: `ocs_query` (ровно одно тело), `ocs_measure` (габариты, объём), `ocs_audit` (0 ошибок), `ocs_save_verified` с уникальным путём DWG. Для проверки повторно открой сохранённый DWG.
- Для быстрой изометрии доказан `-VIEW _SWISO`, затем `ZOOM E` и `ZOOM 0.70X`; снимок возвращает `ocs_capture`, PDF — `ocs_execute` с `op=plot`, `layout=Model`, `fit=true`, `center=true`. Если эти дополнительные действия задерживаются или недоступны, сохрани проверенный DWG и **завершай задачу**, ясно сообщив ограничение. Не ищи десятки альтернативных команд.
- Не выдавай PDF-предпросмотр за полностью оформленный производственный чертёж.

## Подтверждённый вывод PDF и размерные виды (12.11.2026)
- Для 2D проверены прямые команды `PLINE x1,y1 ... C`, `CIRCLE x,y R`, `DIMLINEAR x1,y1 x2,y2 x3,y3` и `TEXT x,y height angle ТЕКСТ_С_ПОДЧЁРКИВАНИЯМИ`. Русские буквы и Ø в DWG поддерживаются.
- Два вида (XY и XZ) можно создать как **неассоциативные** отдельные 2D-контуры по заданным координатам. Не называй их автоматической проекцией модели; для производства нужна сверка и рабочее оформление.
- Важная особенность: после открытия DWG семь `Dimension` могут порождать дополнительные `Line`, `Solid` и `Text`. Проверяй семь размерных объектов и значения размеров, а не требуй ровно пять всех `Text`.
- Рабочая схема вывода PDF OpenCADStudio: `ocs_execute` с `request={"op":"plot","request_id":"уникальный","path":"/home/ocstest/opencadstudio/results/sol-pilot/уникальный.pdf","layout":"Model","fit":true,"center":true}`. Поля `path/layout/fit/center` должны быть **непосредственно внутри request**, не во вложенном `parameters`. Точно такая структура успешно отработала в `OpenCADStudio --serve` на сохранённых DWG; в MCP передавай её без вложенного `parameters`.
- Рабочий снимок: установить `-VIEW _TOP` для плоского вида или `-VIEW _SWISO` для 3D, затем `ZOOM E`; `ocs_capture` возвращает PNG. После проверенного DWG не ищи множество альтернативных способов печати: не более двух попыток, затем заверши с понятным ограничением.
- Эталон первого завершённого цикла: [подробный отчёт](https://github.com/dedtsss/kolkhozcad/blob/main/docs/experiments/opencadstudio-codex-finished-cycle-2026-11-12.md).


## Проверенный опыт: восстановление секционных видов непосредственно из 3D (12.11)
- Для демонстрационной плиты `codex-real-20261112-ribbed-plate.dwg` сделан местный построитель **воспроизводимых сечений** `/home/ocstest/opencadstudio/regenerate_sections.py`. Запуск от `ocstest`: `python3 /home/ocstest/opencadstudio/regenerate_sections.py /home/ocstest/opencadstudio/results/sol-pilot/codex-real-20261112-ribbed-plate.dwg`.
- Программа **читает сохранённое 3D тело** из DWG, выполняет настоящую команду `SECTION` в плоскостях Z=6, Y=70 и X=100 мм, восстанавливает замкнутые контуры, переводит цилиндрические петли в CAD-`Circle`, получает независимый DWG2018 + PDF с четырьмя размерами **по фактическим габаритам исходной модели**, аудитом и контрольной суммой SHA-256.
- После изменения 3D (на отдельной копии основания расширена ширина 200→220 мм) перестроение изменило и контур, и размерную надпись 200→220; исходный DWG неизменен. Повторный запуск с тем же SHA повторно использует готовую пару файлов, ничего не перезаписывая. Все выходные файлы в `results/sol-pilot/derived-sections/`.
- **Важно:** это НЕ команда FLATSHOT и НЕ автоматические ортогональные виды видимых рёбер. Это три **сечения через конкретные плоскости**. Они не связаны нативной ассоциативностью внутри DWG и обновляются **после повторного запуска** построителя, а не при каждой правке модели. Пока жёстко предусмотрена топология именно испытательной плиты (1 Solid, сечения 6/2/2 контура) — не применяй к другим деталям без адаптации плоскостей и проверок.
- `FLATSHOT` в 2026.45 требует явного предварительного выбора тела, выдаёт **692 отрезка**, в том числе дубли, и при переключении TOP/FRONT/RIGHT создаёт **одинаковые XY-отрезки**, даже в GUI. Не используй её как готовый движок чертёжных проекций до исправления.
- Не путай результаты новых сечений с производственной документацией. Материал, допуски, размеры для изготовления, ЕСКД и проверка нагрузок не подтверждены.
