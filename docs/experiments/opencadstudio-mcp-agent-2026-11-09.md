# OpenCADStudio: постоянный MCP-сеанс и управление моделью, 09.11.2026

**Статус:** реальный двусторонний канал управления CAD по MCP **ПРОВЕРЕН**; отдельный контроллер **GPT-6.1 Sol с вызовами функций написан и установлен, но сквозное исполнение контроллера с настоящим OpenAI API в этой итерации НЕ подтверждено** из-за блокировки секретозависимого вызова системой безопасности инструментального канала. Это честная граница теста, не ошибка CAD и не повод обходить защиту.

## Что было до этого

Первый этап Sol → шаблонный 2D и следующий Sol → 3D-план фланца с 2 попытками, объединением, вычитанием, аудитом и DWG/DXF описаны в [предыдущем 3D отчёте](opencadstudio-sol-3d-2026-11-09.md). Он не доказывал, что модель сама пошагово вызывает MCP и читает результат каждого действия.

## Архитектура нового этапа

`BruceVPS: секрет OpenAI через Bruce Secrets → GPT-6.1 Sol Responses API с function tools → защищённый контроллер /opt/opencadstudio-pilot/sol_mcp_agent.py → существующий SSH/Tailscale Bruce→Hangar → HangarVPS:ocstest → xvfb-run → JSON-lines bridge /home/ocstest/opencadstudio/agent_mcp_bridge.py → настоящий GUI/MCP OpenCADStudio v2026.45`.

- Секреты **не передаются на Ангар**. Управляющая программа запускает SSH с очищенным окружением. Ангар получает только ограниченные CAD-действия и возвращает результаты чертежа.
- Фактически обнаружено **20 инструментов** MCP, включая `ocs_sessions`, `ocs_execute`, `ocs_read`, `ocs_inspect`, `ocs_query`, `ocs_commands`, `ocs_measure`, `ocs_audit`, `ocs_save_verified`, `ocs_capture`, `ocs_run`, `ocs_select`. Новая оболочка **не предоставляет модели все 20 безусловно**: только `cad_inspect`, `cad_help`, `cad_edit`, `cad_query`, `cad_measure`, `cad_audit`, `cad_finish`, с проверкой параметров.
- Разрешённая грамматика: числовые CAD-команды из закрытого списка; `ocs_execute` c `batch/run/start/input/select/undo/redo`; сохранение только в `/home/ocstest/opencadstudio/results/sol-pilot` под автоматически присвоенным именем. Доступ к произвольным файлам, запуск сценариев и команд оболочки через интерфейс модели запрещён.
- Документ и GUI остаются открыты **в одном процессе** на протяжении ряда MCP-вызовов; интерактивные команды правильно обрабатывают пошаговый выбор и `enter`. До булевой операции выделение очищается `select(clear=true)`. Пакетная команда поддерживает до 12 шагов.
- Контроллер GPT-6.1 Sol использует официальный Responses API и `function_call`/`function_call_output` с `previous_response_id`; есть предел **30 раундов, 48 вызовов инструментов**, ограничение времени и диагностический отчёт без секретов. Работа цепочки моделей с последующим `function_call_output` в реальной авторизованной сессии пока не протестирована.

## Фактически проведённые испытания без секретов

1. Под `ocstest` в Xvfb `tools/list` показал 20 реальных команд MCP. `ocs_sessions`, `ocs_new`, `ocs_commands`, `ocs_inspect`, `ocs_execute`, `ocs_query`, `ocs_measure`, `ocs_audit`, `ocs_save_verified`, `ocs_capture` используются реально.
2. Пробный цикл на HangarVPS: **22 обращения к оболочке**, 2 коробки → `UNION` → цилиндр → `SUBTRACT` → измерение → аудит → `finish`, DWG/PDF/PNG, без ошибок.
3. Сквозное соединение **Bruce→Hangar** с тем же исполняемым кодом проверено: `inspect`, `commands`, `query` выполнены через SSH и MCP, без токенов OpenAI.
4. Более сложный **контрольный Г-образный кронштейн** (не создан моделью; последовательность вызовов в проверяющей программе):
   - горизонтальная плита **160×100×10 мм**;
   - вертикальная стенка вдоль заднего края до **70 мм**;
   - два прямоугольных усиливающих выступа;
   - четыре настоящих вертикальных отверстия Ø10 в основании;
   - прямоугольное сквозное окно в вертикальной стенке;
   - 4 исходных тела объединены через `UNION`, 5 тел-резцов вычтены через `SUBTRACT`, после чего остался ровно **один `3D Solid`**.
   - **14 групп вызовов MCP** через реальный SSH, без моделирования редактора.
   - Объём полученного тела **283 023,452 мм³**, аналитический расчёт **283 018,407 мм³**; относительная разница **0,001782%**. Измеренные габариты [0,0,0]..[160,100,70], аудит **0 ошибок / 0 предупреждений**.
   - Независимое повторное открытие DWG: **1 `3D Solid`**, объём сеточной модели **283 038,555 мм³**, внешние габариты сохранены.
   - Реальные DWG, PDF, PNG и JSON находятся в `/home/ocstest/opencadstudio/results/sol-pilot/mcp-agent-20261109-152338-596d24f4.*`.
5. Защитные отрицательные проверки: команды `SCRIPT`, `open /etc/passwd`, внедрение `;` в строку CAD и `finish` пустого чертежа **отклонены**. Неограниченное выполнение программ или чтение файлов моделью через оболочку не предоставляется.
6. Ранее отдельно подтверждено, что GPT-6.1 Sol в OpenAI API возвращает настоящий `type=function_call` при предоставлении функции `cad_commands`. Но дополнительная проба цикла `previous_response_id + function_call_output` была **заблокирована системами безопасности OpenAI до исполнения** в секретозависимом инструменте. Дальнейшие проверки делались только без секрета, без обхода блока.

## Что не сделано

- **Не проведён настоящий многошаговый Sol → MCP → Sol → MCP тест**. Наличие кода контроллера и независимая приёмка канала не означают проверку функционирования с моделью. Никаких признаков запуска этого цикла с секретом на Hangar нет.
- Не испытаны чертёжные размеры, допуски, материал, расчёт прочности, произвольные сложные формы, отверстия по горизонтальным осям и STEP/STL.
- SSH от Bruce всё ещё использует существующую root-идентичность Hangar с переходом в `ocstest`. Перед постоянной эксплуатацией нужна отдельная ограниченная SSH-идентичность с принудительной командой и запретом shell.
- Хранилище Bitwarden не выдаёт самостоятельного машинного токена процессу Hangar `ocstest`; для CAD-сценария он не требуется. Брюс остаётся основным поставщиком секретов.

## Следующий шаг

Запустить `sol_mcp_agent.py` в **разрешённом секретозависимом сеансе BruceVPS** со значением `OPENAI_OPENCADSTUDIO_API_KEY` внутри `OPENAI_API_KEY`, не выдавая ключ в инструментарий/модель. Дать модели новое инженерное задание на кронштейн; доказать её индивидуальные запросы `cad_help`, `cad_edit`, `cad_query`, `cad_measure`, `cad_finish` и исправление ошибки. Затем проверить файл повторным открытием и независимым размерным аудитом. Не повторять отклонённый вызов через универсальный терминал в обход блока безопасности.
