# Статус КолхозCAD

Дата: 2026-10-27
**Текущая цель: только первая точная 3D-модель исходной рамы TODOMA.** Предыдущая идея универсальной инженерной платформы отложена, не является активным скоупом.

## Что реально сделано

- На **BrainVPS** подготовлена отдельная папка `/home/brainremote/kolkhozcad/`, Python 3.12 venv, AgentCAD 0.7.0 и его зависимости (build123d, OpenCASCADE, ezdxf). Без Docker, без FreeCAD, без MCP и без отдельных системных служб.
- Необходимые для Python `libGL` зависимости размещены локально под папкой проекта (прав администратора не потребовалось).
- Из существующих фотографий и видеокадров известна общая компоновка: открытый тонкостенный перфорированный профиль, сходящееся дышло, поперечины. Числовые обмеры в рабочее пространство не переданы.
- [Геометрическое испытание](../examples/todoma-demo/): условная рама из 6 деталей с отверстиями, STEP и GLB экспортированы, AgentCAD подтвердил корректность и round-trip STEP; отдельный PNG сформирован программно без виртуального экрана. **Все числовые размеры в демонстрационной модели условные; это НЕ точная рама TODOMA и НЕ чертёж для изготовления.**
- Исполнитель AgentCAD остановлен после теста, постоянные CAD-процессы не работают. Папка среды занимает примерно 1.2 ГБ диска.
- Модель GPT-6 Astra отдельно **не запускалась**: доступный в этом чате инструмент позволяет работать с BrainVPS, но не переключать/передавать задачу в сеанс Astra.

## Следующее действие

Использовать уже работающий AgentCAD на BrainVPS для создания **точной модели TODOMA**. Требуются достоверные численные обмеры, доступные исполнителю, включая сечение лонжеронов, основные длины/ширины, размеры и положение отверстий/изгибов/поперечин. Фотографии и видео в беседе не считать автоматически переданными на сервер.

Дальше — показать владельцу изображение и 3D, поправить по замечаниям, и только после этого обсуждать рессоры и дополнительные функции. FreeCAD/MCP/сервисы/Workspace Agent не являются предварительными условиями.

[Одна задача для ближайшего этапа — #1](https://github.com/dedtsss/kolkhozcad/issues/1). Старый подробный `docs/specs/portable-engineering-mvp.md` остаётся историей обсуждения, не активным заданием.
